POVLabel Editor — guide

A label-placement editor for POV-Ray / XSeed crystallographic figures. Load a rendered PNG and its paired LBL file, drag labels to their final positions, tweak font properties, then export a new PNG or save the updated LBL.

Loading files

  • Drop a PNG and/or LBL file anywhere on the page. Both can be dropped at the same time.
  • Files are routed by extension and can be dropped in any order.

Canvas interaction

Drag labelMove it to a new position.
Click labelSelect it for editing in the properties panel.
Shift-click labelSelect / deselect all labels of the same element type.
Ctrl-click labelAdd / remove from multi-selection.
Double-click atom centreToggle label visibility.

Keyboard shortcuts

Ctrl+ZUndo the last label drag.
+ / −Zoom in / out.
FFit image to window.
Delete / BackspaceToggle visibility of selected label(s).
EscapeDeselect all / close guide.

Properties panel

Use Selected scope to edit the currently selected labels, or All labels to change a property globally. Colour mode Atom matches the label colour to the atom ball colour; Custom lets you pick any colour.

RSC format

Tick RSC format to display labels in Royal Society of Chemistry style: C(1) instead of C1. This is saved into the LBL header when you export.

Export

Export PNG renders the image at its original pixel resolution with labels composited at full quality. Save LBL writes the updated label settings back to the original format, preserving the file header and all atom data.
