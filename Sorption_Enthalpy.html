Sorption Enthalpy Calculator

User Guide

Overview

This app computes the isosteric enthalpy of adsorption (−ΔHads) as a function of loading using the Clausius–Clapeyron approach. It reads fitted isotherm files exported from the Sorption Isotherm Fitter and requires isotherms at two or more temperatures for the same sorbent–sorbate pair.

Clausius–Clapeyron Method

At constant loading q, the isosteric enthalpy is related to the temperature dependence of the equilibrium pressure by:

d(ln p) / d(1/T) = −ΔHads / R

For each loading value q in the overlap region, the app inverts each isotherm to find the equilibrium pressure p(T, q), then fits a straight line to ln(p) vs 1/T. The slope × (−R) gives ΔHads in J mol⁻¹. With ≥3 isotherms the fit quality can be assessed from the linearity of the plot.

Isotherm Inversion

For analytical models (Henry, Langmuir, Freundlich, L-F, DSL, DSLF, Toth) analytical inverses are used where they exist; for all other models a fast bisection solver is used. The loading range is automatically restricted to the region where all loaded isotherms have a valid solution.

Loading Files

Click Add Isotherm and drop or browse for a CSV file exported from the Sorption Isotherm Fitter. The app reads the model, parameters, pressure units, and TemperatureK automatically. If temperature is not in the file it can be entered manually. Add one file per temperature.

Shared Metadata Vocabulary

This app is part of a suite of sorption tools for (1) unit conversion, (2) isotherm fitting, (3) IAST calculations, and (4) sorption enthalpy calculations. Metadata keywords are passed through from the input file to the output CSV, ensuring data continuity through the pipeline.

Tips

For reliable results use at least 3 temperatures spanning ≥20 K. The C–C plot should show good linearity; curvature indicates that ΔHads is loading-dependent at that loading (which is physically meaningful for heterogeneous surfaces). The enthalpy is most reliable within the loading range covered by all isotherms; extrapolation is not performed.
