PXRD Simulator -- guide

Simulates powder X-ray diffractograms directly from CIF files, symmetry-correctly, and turns them into publication-ready figures. Everything runs locally in the browser; no data leaves this page.

Quick start

  • Drop one or more CIF files anywhere on the page. Each becomes a pattern with its own colour.
  • Optionally drop an experimental file (.xy, .xye, .dat, .csv -- two columns, 2θ & intensity; comment lines and a single-number wavelength header line are skipped).
  • Adjust, then export as PNG (raster), SVG (vector, text remains editable), or .xy data.

Comparing patterns

  • Stack offset turns overlaid patterns into a waterfall -- ideal for polymorph or variable-temperature series.
  • Difference curve appears below the pattern when exactly one simulated and one experimental pattern are visible (linear scale, no stacking).
  • Reflection markers add Rietveld-style tick rows, one per simulated pattern.
  • Click a pattern card to select it -- the structure panel, peak list, hkl labels and .xy export follow the selection.

Plot interaction

  • drag horizontally to zoom into a region; double-click or the Reset-zoom button restores the full range.
  • Hovering reports the cursor position, plus the nearest reflection (hkl, d, I) of the selected pattern.
  • Hovering a row in the peak list highlights that reflection on the plot.

Physics notes

  • Intensities: |F|² from Cromer-Mann form factors with isotropic Debye-Waller damping (Uiso; Biso converted; default 0.025 Å² when absent), site occupancies, multiplicity from the CIF symmetry operators, and the Lorentz-polarization factor (1+cos²2θ)/(sin²θ cosθ).
  • Profiles: pseudo-Voigt with shared FWHM and mixing parameter η.
  • Kα₂ doublet adds satellites at the tabulated α₂ wavelength with adjustable intensity ratio (0.5 typical).
  • Preferred orientation uses the March-Dollase model averaged over symmetry-equivalent reflections.
  • Elements without tabulated Cromer-Mann coefficients are approximated by Z-scaling the nearest tabulated element; a notice appears when this happens.

Publication sizing

Pick a journal preset under Figure Size (85 mm single-column, 170 mm double-column at 300 dpi), then export PNG at 2× for an effective 600 dpi, or use SVG and finish in Illustrator/Inkscape.
