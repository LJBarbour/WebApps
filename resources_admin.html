Adding a new user
To grant a new person access to the resources page, follow these two steps:
  1. Go to the Supabase dashboard → Authentication → Users → Add User → Send Invitation, and enter their email address. They will receive an email invitation to set their password.
  2. Once they have accepted the invitation, reload this page — they will appear in the user list below. Use the toggle to grant them resources access.
New users invited this way are external (resources access only) and will not appear in instrument booking lists.
