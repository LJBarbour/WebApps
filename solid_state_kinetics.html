How to Use This App

Overview

This app fits solid-state reaction kinetic models of the form f(α) = kt + b to thermogravimetric or similar time-series data. Load your data, select the reaction range, inspect the α(t) curve, then test kinetic models on the linear transformed plot.

Step 1 — Load Data

Drop a CSV file anywhere on the app, or click Browse for file. The file must have two numeric columns: time (column 1) and mass or signal (column 2). A header row is skipped automatically. Enter the time unit (e.g. s, min, h) in the Units field so that the rate constant k is reported with correct units.

Step 2 — Set Reaction Bounds

On the Raw Data tab, click on the plot to set two boundaries:

  • t₀ (green dashed line) — where the reaction begins. Click at the start of the uptake/release event.
  • t∞ (red dashed line) — where equilibrium is reached, i.e. where the curve flattens. Click at the end of the event.

You can also type values directly into the t₀ / t∞ fields and click Apply. Values are snapped to the nearest data point. Use Reset Selection to start over.

Step 3 — Inspect α(t)

Switch to the α(t) Curve tab. The selected segment is rescaled so that α runs from 0 (at t₀) to 1 (at t∞), and time is shifted to start at zero. The curve shape gives a qualitative indication of the likely kinetic mechanism before any fitting is attempted.

Step 4 — Fit a Kinetic Model

Choose a model from one of the four groups in the left panel. The app automatically switches to the Model Fit tab, where f(α) is plotted against time. A good model produces a straight line. The regression parameters (k, b, R², n) are shown directly on the plot in the Annotation box — toggle or reposition it from the right-hand panel.

The equation of the selected model is displayed in the canvas below the model selector.

Step 5 — Zoom & Refine

Left-drag on the Model Fit plot to draw a zoom rectangle — the plot rescales to that region and the regression is immediately recomputed from only the visible points. Right-drag to pan. Click ⟲ Reset to return to the full range. This lets you identify the range over which the data are most linear and obtain the best-fit k for that regime.

Step 6 — Export

Two export options are available on the right-hand panel, under Output (Model Fit tab):

  • Save Plot Image / Copy Plot to Clipboard — renders the current Model Fit plot as a PNG, at a chosen size preset or a custom pixel size, respecting all style settings (fonts, colors, labels, line widths).
  • Export Results CSV — saves a spreadsheet with the regression parameters and the full α, f(α), and residual data for the selected range.

Saved files default to the folder your data file came from, when your browser supports it.

Kinetic Models

The following model families are available:

Group Models Mechanism
NucleationP2, P3, P4, A2, A3, A4Nucleation and growth (Power Law and Avrami-Erofeev)
Geometrical ContractionR2, R3Shrinking core (contracting area or volume)
DiffusionD1, D2, D3, D41D, 2D (Valensi), 3D (Jander), Ginstling-Brounstein
Reaction OrderF1, F2, F3First, second, and third order
Tip: A model fits well if its f(α) vs time plot is linear over a wide range of α. Compare R² values, but also look for systematic curvature — a high R² over a narrow zoom window may still indicate a poor model. The intercept b should be small relative to the signal; a large b may indicate an induction period or a poor choice of t₀.
