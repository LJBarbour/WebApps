FT-IR Plotter

User Guide

Overlay and annotate FT-IR spectra for publication-ready figures. Everything runs locally; no data leaves the browser.

Loading spectra

  • Drop one or more .dpt, .csv, or .txt files anywhere on the app. Each becomes its own spectrum, coloured automatically.
  • Two-column whitespace/comma/semicolon/tab-delimited data: column 1 = wavenumber (cm⁻¹), column 2 = intensity.
  • Each spectrum gets a card in the left panel with a colour swatch, an editable label (defaults to the file name), a visibility toggle, a delete button, and its own Y offset for stacking.

Y axis

Intensity is arbitrary units, so the Y axis shows only its label, with no tick marks or values. Raw plots the data as-loaded. Transmittance and Absorbance convert assuming the raw values are fractional transmittance (or % T if > 1). Normalise scales each spectrum independently: 0–1 or area = 1.

Annotations

Type a wavenumber and label (use the Greek/chemistry palettes to insert special characters), or pick from the plot by clicking the crosshair button then clicking on the spectrum. Annotation labels are draggable vertically on the canvas. Each annotation can be edited or removed individually.

Plot interaction

  • drag across the plot to zoom the wavenumber range; double-click or Reset to restore the full range.
  • A floating tooltip reports the wavenumber and each spectrum's value at the cursor.

Output

Save Plot Image (PNG, at the chosen size preset), Copy Plot to Clipboard, merged CSV, and settings JSON round-trip.
