Software how-to
Fiji: making a movie from hot-stage images

Assumes a sequence of images named sequentially, e.g. Image001.jpg … Image175.jpg.

StepAction
1  Prepare Place all images in a single folder.
2  Open Fiji Launch Fiji.
3  Import File → Import → Image Sequence
Select the first image. Fiji detects the sequence automatically and loads all images as a stack.
4  Preview Image → Stacks → Animation → Start Animation
Plays the movie immediately in Fiji.
5  Speed Image → Stacks → Animation → Animation Options
Recommended frame rates and resulting durations for 175 images:
fpsDurationBest for
535 sSlow, detailed viewing
1017.5 sConference presentation ✓
1511.7 sSmooth, fast overview
6  Export File → Save As → AVI
Choose JPEG compression for a smaller file, or PNG / Uncompressed for higher quality.

Making it publication-ready

For a conference or publication, consider adding overlays to each frame before exporting:

  • Temperature (lower-left corner)
  • Sample name
  • Heating rate (e.g. 10 °C min⁻¹)
  • Scale bar

Auto-stamping temperatures on each frame

If the temperatures are known, Fiji can automatically stamp each frame with the current temperature (e.g. 25 °C, 30 °C, 35 °C …), so the viewer can see exactly when melting, crystallisation, or phase transitions occur — particularly valuable for DSC correlation and polymorph studies. To use this feature, you need to know:

  • Starting temperature
  • Final temperature
  • Temperature increment between images
Windows tips
Restore classic right-click menu in Windows Explorer

Windows 11 replaced the familiar right-click context menu with a simplified version. To restore the classic menu:

  1. Open Command Prompt as Administrator.
  2. Run this command:
    reg.exe add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
  3. Restart Explorer using one of these methods:
    • Press Ctrl Shift Esc → find Windows Explorer → right-click → Restart
    • Or simply reboot the PC.
Revert to the Windows 11 right-click menu
  1. Run this command:
    reg.exe delete "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}" /f
  2. Restart Explorer as above.
