Sorption Unit Converter

User Guide

Overview

This app loads gas-sorption isotherm data from a CSV file and interconverts the uptake capacity between different unit systems. Both adsorption and desorption branches are supported. The converted data can be exported as a new CSV.

Loading data

Drag and drop a CSV (or delimited text) file onto the drop zone in the left sidebar, or click Browse for file. Column 1 should be pressure, column 2 uptake, separated by commas, tabs, or semicolons.

Adsorption / desorption: two blocks of data separated by one or more blank lines (or lines containing only delimiters) are treated as adsorption followed by desorption. Adsorption is plotted with filled circles, desorption with open circles.

Header row: a non-numeric first row is parsed for units — for example Pressure (mbar) sets the pressure unit to mbar, and Uptake (mmol/g) sets the uptake unit. If no header is detected, bar and mmol g⁻¹ are assumed.

Metadata keys

Before the data block you can embed key–value rows that the app reads automatically:

KeyEffect
SorptiveSets the gas (e.g. CO2, methane, N2)
TemperatureKTemperature in K
TemperatureCTemperature in °C (converted to K)
Host_FormulaParses molecular formula and calculates MW
Host_MWHost molecular weight (g mol⁻¹)
Host_DensityHost density (g cm⁻³)
Host_MassHost sample mass (mg)

If both Host_Formula and Host_MW are given and disagree by more than 1%, a warning is shown in red.

Choosing units

Set the input units (left sidebar) to match your data file. Set the output units to your target system. Conversion happens automatically when you change the output units, provided all required parameters are available. Otherwise, fill in the missing values and click Convert Units.

On file load, the app always converts to mmol g⁻¹ vs bar as a baseline. You can then select any output units you like.

cc(STP) and real-gas correction

The ideal-gas molar volume at STP (0 °C, 1 atm) is 22.414 mL mmol⁻¹. When a gas preset is selected, the van der Waals equation is solved iteratively at STP to give a more accurate molar volume — for example CO₂ gives ≈ 22.26 mL mmol⁻¹. The value used is shown in the conversion summary.

Molecular formula parser

Enter standard formulae in the Host Material panel, e.g. Zn4O(BDC)3 or Co2(OH)2(bbta). Parentheses and fractional stoichiometries are supported. Abbreviations for organic linkers (BDC, dobdc, etc.) are not resolved — enter the MW directly in those cases.

Plot controls

The collapsible panels on the right adjust fonts, colours, axis ranges, and labels independently for the Raw and Converted plots. Axis labels default to detected unit notation (e.g. Uptake / mmol g⁻¹) but can be overridden. Click Save Plot Image to export at a specified pixel size.

Exporting converted data

After conversion, click Export Converted CSV in the left sidebar. The file includes a comment header recording the units and conversion applied.

Supported gases

CO₂, CH₄, N₂, O₂, H₂, C₂H₂ (acetylene), C₂H₄ (ethylene), C₂H₆ (ethane), C₃H₆ (propylene), C₃H₈ (propane), C₄H₁₀ (butane), NO, NO₂, N₂O, H₂O, SO₂, H₂S, NH₃, Ar, He, Kr, Xe. For any other gas select Custom and enter the molecular weight manually.
