Sorption Unit Converter

User Guide

Overview

This app loads gas-sorption isotherm data from a CSV file and interconverts the uptake capacity between different unit systems. Both adsorption and desorption branches are supported. The converted data can be exported as a new CSV. On load, the app always opens on the Converted tab, so you see the result — or, if metadata is still missing, an empty plot with the left-hand panel showing why — immediately.

Loading data

Drop a CSV (or delimited text) file anywhere on the app. Column 1 should be pressure, column 2 uptake, separated by commas, tabs, or semicolons.

Adsorption / desorption: two blocks of data separated by one or more blank lines (or lines containing only delimiters) are treated as adsorption followed by desorption. Adsorption is plotted with filled circles, desorption with open circles.

Header row: a non-numeric first row is parsed for units — for example Pressure (mbar) sets the pressure unit to mbar, and Uptake (mmol/g) sets the uptake unit. If no header is detected, bar and mmol g⁻¹ are assumed.

Metadata panel

Loading a file always clears any previously-entered metadata first, then fills in whatever the new file specifies — nothing carries over from a file you loaded earlier. Anything not read from the file (sorptive identity, molecular weight, Psat, temperature, host formula, host MW, host mass) can be entered directly in the METADATA section of the left sidebar, below Input/Output Units.

A field with a pink background is a value the current output units genuinely need and that is still missing. A field with only a red outline could supply that same value a different way — e.g. the host formula can derive the host MW, and the sorptive identity + temperature can derive Psat via the Antoine equation. Enter either route and both the pink field and its red-outlined alternative clear together.

Choosing units

Set the input units (left sidebar) to match your data file. Set the output units to your target system — conversion happens automatically as soon as all required parameters are available. If something's missing, the required field turns pink in the METADATA panel (see above), and the Converted plot stays empty until it's filled in.

On file load, the app always converts to mmol g⁻¹ vs bar as a baseline. You can then select any output units you like.

The app only ever asks for what your specific input→output pair actually needs, which is often less than this table's per-unit list would suggest — it's written against the mmol/g baseline. For example, converting between two absolute mass units (µg ⇄ mg ⇄ g) needs neither gas MW nor host mass, since both cancel out; converting between two relative mass units (e.g. g/g ⇄ wt%) needs neither either. Gas MW is only asked for when the amount kind actually changes (mass ⇄ moles), and host mass only when relative and absolute amounts are actually being converted between each other.

cm³(STP) and real-gas correction

The ideal-gas molar volume at STP (0 °C, 1 atm) is 22.414 mL mmol⁻¹. When a gas preset is selected, the van der Waals equation is solved iteratively at STP to give a more accurate molar volume — for example CO₂ gives ≈ 22.26 mL mmol⁻¹. The value used is shown in the conversion summary.

Molecular formula parser

Enter the host formula using standard element symbols and integer stoichiometries, e.g. C24H16N2O8Zn2 or C3H3N3. Parentheses with numeric multipliers are supported, e.g. Zn2(C8H4O4)2(H2O)2. Only element symbols are recognised — abbreviations for organic linkers (BDC, DOBDC, etc.) are not resolved. If the formula contains such abbreviations, enter the molecular weight directly in the Host MW field instead.

Plot controls

The collapsible panels on the right adjust fonts, colours, axis ranges, and labels independently for the Raw and Converted plots. Axis labels default to detected unit notation (e.g. Uptake / mmol g⁻¹) but can be overridden. Click Save Plot Image to export at a specified pixel size.

Exporting converted data

After conversion, click Export Converted CSV in the right-hand panel (Output section). The file includes a comment header recording the units and conversion applied.

Shared metadata vocabulary

This app is part of a suite of sorption tools for (1) unit conversion, (2) isotherm fitting, (3) IAST calculations, and (4) sorption enthalpy calculations. Metadata keywords are passed through from the input file to the output CSV, ensuring data continuity through the pipeline.
