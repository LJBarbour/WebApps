What is an O-Ring?

A primer on how O-rings work, where they're used, and how to navigate this guide.

The Basics

An O-ring is a torus-shaped elastomeric seal. When compressed into a machined groove it deforms to fill any gap between mating surfaces, blocking fluid or gas.

The seal is self-energising — system pressure forces the rubber harder against the low-pressure side, so it seals better under higher pressure. Typical squeeze: 15–30% static, 8–16% dynamic.

Application Types

Static — O-ring does not move once installed. Sub-types: axial (face seal), radial (bore seal), dovetail, and boss seals.

Dynamic — O-ring experiences movement. Sub-types: reciprocating (linear back-and-forth), oscillating (limited rotation), and rotary (continuous low-speed spin).
