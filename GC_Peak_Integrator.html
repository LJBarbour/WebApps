GC Peak Integrator

User Guide

Detect, edit, and integrate chromatography peaks, and export publication-ready figures. Everything runs locally; no data leaves the browser.

Loading data

  • Drop one or more files anywhere on the app — one at a time, or several together. Every dropped file adds to the same running set, in the Compare Files list on the left; check exactly one to view it as the single-file workspace (peak detection, manual peaks, and the peak table all work on it), or check two or more to switch automatically to a normalized, vertically-offset stack plot.
  • Click Load Demo Data to try it with sample data.
  • Chromeleon-style exports (with a Time (min) / Step (s) / Value header and metadata block) are read automatically.
  • Headerless files are also supported: column 1 is retention time; if a third column is present, column 3 is intensity (column 2 is typically a step/interval column and is ignored).

Peak detection & selection

Automatic finds peaks within whatever X range is currently displayed (set that range in Axis Ranges, or zoom/drag on the plot first), using a height threshold, smoothing window, and minimum separation. Values are a fraction of the tallest baseline-corrected signal; values much below 1% may start picking up baseline noise. Each peak's baseline is a straight line between its start and end boundary points (valley-to-valley integration). Peak height/area are always measured on each curve's real, untouched intensity values — never the normalized/offset numbers used just for display — so results stay correct no matter which Normalize mode or stack offset is showing.

Manual lets you click a start point then an end point on the chromatogram to define a peak directly. Start/End can also be fine-tuned by typing into the peak table.

In the stack plot, the same section gives every loaded curve its own independent peaks. Detect Peaks (All Curves) runs the same Automatic settings on every visible curve at once — a quick way to quantify several samples together without switching curve by curve; Detect Peaks (Target Curve) runs it on just the curve chosen in "Target curve". In Manual mode, clicks always add to the selected Target curve.

Peak table

Below the chart: RT, start, end, height, area, and %area for every peak, editable inline. The panel can be collapsed or resized by dragging the grip above it.

Axis ranges & zoom

Set X min/max directly, or drag across the plot (crosshair cursor) to select a range and double-click or Reset zoom to restore the full range. The Y axis is always in arbitrary units — it has no tick marks or values, and always scales automatically to fit whatever's currently displayed; there's no manual Y range. Y scale can still be switched between Linear and Log. Tick interval sets an exact fixed spacing between X ticks; leave it blank for automatic "nice" spacing. In the stack plot, only X range, X tick interval, and Reset zoom apply.

Plot appearance

Full control over typography (fonts and sizes for axis labels and ticks), grid/tick/frame styling, trace and peak colours and shading, an optional peak colour legend, and number formatting — grouped into dropdown sections throughout. X-axis tick decimals are chosen automatically from the current zoom level, so labels never show more precision than the tick spacing needs; the Y decimals/format controls (Auto/Fixed/Scientific) apply to the peak table and tooltip, since the axis itself never shows numbers. Use Undo (or Ctrl+Z) in the header to step back through recent style or content changes one at a time.

Output

Exports reflect the current X zoom and everything currently shown on the plot — the single chromatogram or the stack plot, whichever is active. Width/height set the figure layout; PNG scale multiplies final resolution without changing proportions. Export peak table (CSV) exports the peak table for a single chromatogram, or one time/value block per curve (using its plotted, normalized value) for the stack plot. In the stack plot, Export peak table, all curves instead exports every curve's own peak table (RT/start/end/height/area/area%) — always computed from that curve's real, untouched Y values with its true retention times, never the normalized/offset display numbers, regardless of which Normalize mode is showing. Save dialogs let you choose the file name and folder, starting from wherever the data file was loaded.

Both exported CSVs can be loaded straight back in (drop them in like any other file) - the single-chromatogram export recovers the sample name and its exact x,y curve, and the stack-plot export rebuilds every curve it contained, complete with names and colors, so you can pick up a saved comparison again later.

Compare files

The Compare Files list in the left panel accumulates every file you drop, one at a time or several together. The view switches automatically based on how many are checked (visible): check exactly one file and it's shown as the single-file workspace; check two or more and the main view switches to the stack plot.

Drag a file up or down in the list (using the ⋮⋮ handle) to reorder it — that order drives "As loaded" / "Reverse loaded" stacking, so it controls which trace ends up on top or bottom. Curve colours are editable both in that list and in Stack Appearance → Curve colors, and stay in sync either way.

Axis Ranges, Typography, Frame/Ticks/Grid, Legend, Annotation, and Output are shared between both views, so a stack plot can be styled and exported to the same publication-quality standard as a single chromatogram. Each curve gets an editable, colorable, movable text-box label just above its baseline the first time it appears (Stack Appearance → Auto-label curves, sized by Auto-label size); the Axis Ranges Y label field can add a separate Y-axis title alongside them. Normalization, stacking, and per-trace appearance have their own sections that only appear while the stack plot is showing.

Normalization & Stacking: each trace is normalized independently, then offset vertically by the stack offset so traces don't overlap (set offset to 0 to overlay all traces on one baseline). "Max = 1" compares shapes only; "Area = 1" and "Raw" preserve relative amplitude between files, rescaled to a shared display height; "Original Y values" applies no scaling at all, keeping each curve's true untouched intensity values, with the stack offset then measured as a fraction of the tallest curve's actual height.

Annotation

Adds free-floating text-box labels on top of either view — drag one directly on the plot to reposition it. Each box has its own text, font, size, colour, bold/italic, and can be deleted independently. Check two or more boxes in the list, choose an alignment, and click Go to line up their left edges, right edges, or centres. Text boxes are included in exports and are shared between the single chromatogram and stack plot views.

Choosing colours

Clicking any colour swatch anywhere in the app opens a picker with three tabs: Palette (quick-pick swatches, a tint/shade grid, and your recent picks), Custom (a saturation/brightness gradient, a hue slider, and editable R/G/B fields), and Wheel (a full hue/saturation colour wheel plus a grayscale strip).
