GC Peak Integrator — guide

Detect, edit, and integrate chromatography peaks, and export publication-ready figures. Everything runs locally; no data leaves the browser.

Loading data

  • Drop a file anywhere on the chart, or use Load File / Load Demo.
  • Chromeleon-style exports (with a Time (min) / Step (s) / Value header and metadata block) are read automatically.
  • Headerless files are also supported: column 1 is retention time; if a third column is present, column 3 is intensity (column 2 is typically a step/interval column and is ignored).

Peak detection & selection

Automatic finds peaks within whatever X range is currently displayed (set that range in Axis Ranges first), using a height threshold, smoothing window, and minimum separation. Each peak's baseline is a straight line between its start and end boundary points (valley-to-valley integration).

Manual lets you click a start point then an end point on the chromatogram to define a peak directly. Start/End can also be fine-tuned by typing into the peak table.

Peak table

Below the chart: RT, start, end, height, area, and %area for every peak, editable inline. The panel can be collapsed or resized by dragging the grip above it.

Axis ranges

Set X and Y min/max directly, or drag across the plot to zoom and double-click or Reset zoom to restore. Y min/max are optional manual overrides — leave them blank to autoscale. Y scale can be switched between Linear and Log.

Plot appearance

Full control over typography (fonts and sizes for title, axis labels, and ticks), grid/tick/frame styling, trace and peak colours and shading, background, an optional peak colour legend, and number formatting — grouped into the same dropdown sections throughout. X-axis tick decimals are chosen automatically from the current zoom level.

Export

Save PNG (at a chosen figure size × scale), Save SVG (true vector), Copy to clipboard, and Export peak table (CSV), which also includes the raw x,y data for the currently displayed X range. Save dialogs let you choose the file name and folder, starting from wherever the data file was loaded.
