📖 Dial Gauge Generator — User Guide

What Is Dial Gauge Generator?

Dial Gauge Generator is a self-contained, browser-based tool for designing high-quality dial gauge graphics. It runs entirely in your browser — no installation, no server, no internet connection required — and exports pixel-perfect PNG images ready for dashboards, reports, presentations, and HMI mockups.

Every aspect of the gauge is configurable in real time. Changes appear on the canvas instantly.

Key Features

  • Real-time canvas preview — every change reflects immediately.
  • 5 bezel styles with realistic metallic rendering.
  • 5 needle profiles with full colour and dimension control.
  • Three-level tick hierarchy: major, semi-major, and minor.
  • Colour zones for safe / warning / danger banding.
  • Arc track and progress arc overlays.
  • Title and live numeric value display.
  • Save & load complete configurations as JSON.
  • Export as a high-resolution transparent PNG.

Supported Browsers

  • Google Chrome 90+ (recommended)
  • Microsoft Edge 90+
  • Mozilla Firefox 88+
  • Apple Safari 14+
Tip: For best export quality and clipboard support, use Google Chrome or Edge.

Angle Convention

All angles use a clock-face convention: 0° is at 12 o'clock, positive values rotate clockwise. The default sweep of −125° to +125° produces the classic 250° arc seen on most industrial gauges.

PresetStart °End °Use Case
Standard (250°)−125+125Most industrial / automotive gauges
Full circle (360°)−180+180Progress rings, clock faces
Half dial (180°)−90+90Dashboard-style semicircle
Quarter dial (90°)0+90Corner-mounted indicators

Layout

The application is divided into two areas: the Settings Sidebar on the left and the Canvas Area on the right.

The sidebar contains all controls, grouped into collapsible sections. Click any section header to expand or collapse it. The canvas shows a live preview on a checker-pattern background — the checkers are a display aid only and do not appear in exported images.

Note: At very small canvas sizes (below ~250 px) tick and label strokes may render below one pixel and become invisible. Increase Canvas Size if elements disappear.

Tick Hierarchy

Tick marks are drawn in three levels of detail. All three share the single Tick Colour setting.

Major Ticks

Mark primary scale divisions. Always visible. A numeric label is drawn at each major tick (see Labels below).

SettingDescriptionDefault
CountNumber of intervals. Total ticks = Count + 1.10
LengthStroke length in pixels.18 px
WidthStroke width in pixels.2.5 px

Semi-Major Ticks

Subdivide major intervals. Finer than major, coarser than minor.

SettingDescriptionDefault
Enable toggleShow or hide semi-major ticks.On
Per GapEqual parts each major interval is divided into. 2 = midpoint tick.2
Length / WidthStroke dimensions in pixels.12 / 1.5 px

Minor Ticks

Finest graduation level, subdividing each major interval.

SettingDescriptionDefault
Enable toggleShow or hide minor ticks.On

Tip: Major Count 10, Semi Per 2, Minor Per 10 gives the standard layout of most industrial gauges.

Arc Track

Two optional arc overlays are drawn along the gauge sweep path, inside the tick marks.

Track Ring

A full-sweep background arc, typically used as a subtle backdrop.

SettingDescriptionDefault
Show Track RingEnable/disable.Off
Track ColourColour of the arc stroke.#e0e0e0
Track WidthStroke width in pixels. Also controls Colour Zone width.8 px

Progress Arc

Drawn from the minimum position up to the current value.

SettingDescriptionDefault
Show Progress ArcEnable/disable.Off
Progress ColourColour of the progress arc.#cc0000
Progress WidthStroke width in pixels.8 px

Line Cap

Controls how arc stroke ends are rendered. Applies to both track ring and progress arc.

  • Round — semicircular caps. Polished and modern. (Default)
  • Butt — flat caps flush with endpoints. Clean and precise.
  • Square — flat caps extending slightly beyond endpoints.

Colour Zones

Coloured arc segments drawn along the sweep path to mark ranges such as safe operating limits, warning thresholds, and danger zones. Any number of zones can be added.

Adding and Removing Zones

  • Click + Add Zone to add a new zone with default values.
  • Each zone row has From (start value), To (end value), and Colour.
  • Click ✕ to remove a zone. Changes apply immediately.
Note: Zone arc width follows the Track Width setting in Arc Track. Zones are rendered beneath the track ring and progress arc, but above the dial face.
Tip: Common pattern — Green 0–60, Orange 60–80, Red 80–100. Or a single Red 85–100 for a minimal danger band.

Saving & Loading Settings

  • 💾 Save Settings to File — downloads a dial-gauge-settings.json file with all current values, including colour zones.
  • 📂 Load Settings from File — opens a file picker. Select a previously saved JSON file to restore all settings instantly.
Note: Settings files are plain-text JSON and can be edited in any text editor for precise adjustments or batch configuration.

Exporting the Image

  • 📋 Copy as PNG — copies the gauge to your clipboard. Paste into Word, PowerPoint, Slack, etc. Requires Chrome or Edge.
  • ⬇️ Download PNG — downloads dial-gauge.png at the exact canvas size. Background is transparent.
Tip: Set Canvas Size to 800–1200 px for print-quality output. The transparent background lets you place the gauge over any background in downstream software.

Troubleshooting

ProblemSolution
"Copy as PNG" failsUse Download PNG instead. Clipboard requires Chrome or Edge.
Labels overlap ticksIncrease Label Offset to push labels further inward.
Zones not visibleZones share the Track Width. Ensure Track Width is large enough (≥6 px). The track ring may be covering zones — try disabling it.
Needle points wrong wayCheck the current value is within Min–Max range.
Canvas appears blankCheck that Min does not equal Max (zero range causes a blank canvas).
Settings file fails to loadEnsure it is a valid JSON file saved by this application. Validate with a JSON checker if edited manually.
Note: The checker-pattern background in the canvas area is a display aid only and never appears in exported PNG images.
