Unmodeled electron recovery

v1.0

A SQUEEZE-style difference-Fourier route to diffuse solvent: build a (Fo−Fc) map from the ordered model, mask the solvent-accessible voids, and integrate the residual density to recover the electrons that were never modelled.

  1. Drop in a CIF of the ordered structure (cell, symmetry operators and refined atoms) and the matching SHELX .hkl (HKLF 4: h k l F2 σ).
  2. Set the probe radius and grid sampling — the defaults mirror common SQUEEZE settings.
  3. Press Recover electrons. You get the electron count per void and per cell, a mask summary, and a browsable difference-density map.

How to read this. The recovered count is the residual density integrated over the solvent-excluded (Connolly) mask — the region swept by a probe rolling over the van der Waals surface, obtained by morphological closing rather than a bare vdW+probe cut-off. Measurements are first merged to the true crystallographically-unique set (by full Laue symmetry, not just exact hkl duplicates), then each unique reflection is expanded back out to every symmetry- and Friedel-related grid point with its own correctly phased structure factor, so the map uses the full measured redundancy rather than leaving most of it to be estimated. This is an independent implementation, not Spek's code: it uses an overall (or shell) scale and an isotropic-equivalent model when only Uiso is available. On test data this tracks PLATON SQUEEZE/masks closely on void geometry — void count, volume, and centroid positions (the last of these correctly handles voids that straddle the periodic cell boundary, e.g. sitting on a special position at or near the origin).

Electron count: leave Iterations at 1. Testing against several reference SQUEEZE/masks results found that a single difference-map pass already matches closely when the low-angle data is complete, and that running further iterations to try to recover missing low-order reflections — the app's own earlier approach — does not converge to a stable answer on any dataset tested; it overshoots progressively the longer it runs, even inventing electrons in voids that are genuinely empty. When the low-angle data does have a real gap (often a beamstop limitation, flagged automatically from the largest measured d-spacing), the single-pass count is a lower-bound estimate with no reliable correction currently available here — use PLATON/masks directly for that number.
