Vx-PXRD Viewer -- guide

Turns a series of powder diffractograms collected under a varying condition -- temperature, pressure, time, humidity, or simply different phases -- into a single publication-ready figure, as either a stacked line/waterfall plot or a 2-D intensity map. Everything runs locally in the browser; no data leaves this page.

Quick start

  • Drop .xy, .xye, .xrdml files, a .zip archive, or a saved series .csv anywhere on the page. The stimulus value is auto-extracted from each filename (last numeric segment) or from XRDML metadata.
  • Drag rows by the grip (⣿) to reorder freely -- essential for cooling/heating cycles. Auto-sort restores ascending-value order.
  • Switch between Stacked and Intensity map at top right; adjust settings on the right; export as SVG (vector), PNG, or copy to clipboard.

Stacked plot

  • Line mode draws each pattern in its own band; Waterfall mode overlaps filled traces with a single shared intensity axis -- the classic VT presentation.
  • Per-pattern colour (swatch on each card) with the Custom scheme, or a scientific colour ramp (Viridis, Plasma, Inferno, Cividis, Cool, Warm).
  • Legends are drawn on the canvas and draggable within each band; the snap selector aligns them by left, centre, or right edge.

Intensity map

  • Horizontal axis 2θ, vertical axis the stimulus, brightness ∝ intensity. By stimulus value places rows at true positions; By sequence order spaces them evenly (for non-monotonic cycles), labelling each with its real value.
  • Reading it: vertical streak = fixed peak; diagonal = shifting peak; fading/appearing = phase transition.
  • Gamma, peak emphasis and a noise floor control contrast. A colourbar can be shown alongside, and peak-track guides can be dropped at chosen 2θ values (see below).

Peak-track guides (intensity map)

Enable Peak-track guides, then click on the map to drop a vertical reference line at that 2θ; click a guide's handle to remove it. Guides export with the figure -- useful for annotating a peak that shifts or splits through a transition.

Plot interaction

  • drag horizontally to zoom the 2θ range; double-click or Reset-zoom restores full range.
  • A floating tooltip follows the cursor with 2θ (and stimulus on the map), visible regardless of scroll.

Series CSV & settings

Export series writes stimulus values, legends, order and all data to a CSV you can re-import later (drag it back in). Save/Load settings (in the Export group) preserves every control choice as JSON -- data not included.

Supported formats

Text (.xy .xye .dat .txt): whitespace/comma-separated, col 1 = 2θ, col 2 = intensity; extra columns and comment lines (# ! ;) ignored. XRDML: X'Pert Pro / Empyrean XML -- 2θ grid reconstructed, non-ambient value extracted (Kelvin converted to °C).
