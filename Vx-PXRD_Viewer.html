About Vx-PXRD Viewer

This app visualises a series of powder X-ray diffractograms collected under a variable condition — temperature, pressure, time, relative humidity, or any other parameter — by combining them into a single figure. It also handles series where the patterns are simply different phases or materials rather than a parametric scan.

Two complementary views are provided: a greyscale (or coloured) intensity map and a more conventional stacked line plot. The same data underlies both views; switch between them with the tabs above.

Workflow

  • On the Files tab, drop your data files, a .zip archive, or a series CSV (see below). The app will try to extract the variable value from each filename automatically.
  • Drag rows by the grip handle (⠿) in the leftmost column to reorder patterns freely — essential for cooling/heating cycles or any non-monotonic sequence. Click Auto-sort to restore Y-value order. Use the ✕ button to remove individual files.
  • Check the Y values and legend labels; edit any that are wrong.
  • Switch to Intensity Map or Stacked Plots, adjust the settings on the right, and the plot updates automatically.

Supported file formats

Plain-text formats (.xy, .xye, .dat, .txt): two or more whitespace- or comma-separated columns; first column is 2θ in degrees, second is intensity. Additional columns (e.g. esd in .xye files from CSD Mercury) are ignored. Single-value header lines and lines starting with #, !, or ; are skipped.

PANalytical XRDML format (.xrdml): XML files produced by X'Pert Pro and Empyrean instruments. The app reads the 2θ start/end positions, reconstructs the angular grid, and extracts the non-ambient condition automatically. Temperature values in Kelvin are converted to °C. XRDML files can be loaded individually or inside a .zip archive.

Series CSV — saving and restoring your work

After arranging and labelling a series on the Files tab, click Export series… to save everything to a CSV. In Chrome and Edge a Save As dialog lets you choose folder and filename; other browsers download automatically. You can also drag a CSV file directly onto the app to import it.

CSV structure: row 0 — Y-axis label; row 1 — stimulus value per pattern (every other column); row 2 — legend label per pattern; rows 3 onwards — 2θ and intensity columns interleaved per pattern. On import the pattern order, Y values, and legend labels are restored exactly.

The intensity map

The intensity map is a 2D image of the entire dataset. The horizontal axis is 2θ, the vertical axis is the variable condition, and pixel brightness encodes intensity. A floating tooltip follows the mouse cursor showing the current 2θ angle and stimulus value — visible anywhere on screen regardless of scroll position.

Y-axis mode controls how the vertical axis is constructed. By stimulus value sorts patterns by their Y value — the standard view for a monotonic scan. By sequence order preserves the table order and spaces rows evenly, with tick labels showing the actual stimulus at each pattern position. Use sequence order for cooling/heating/cooling cycles or any non-monotonic series.

How it is built: each diffractogram is resampled onto a uniform 2θ grid and normalised (default: per-pattern baseline subtraction). For every pixel row the app finds the two bracketing patterns and linearly interpolates between them.

Reading the map: vertical streak = peak fixed in position; diagonal streak = peak shifting with condition; fading/appearing streaks = phase transition.

Contrast and colour: gamma stretches or compresses the intensity scale. Peak and background colours are set independently.

Normalisation: Per-pattern & baseline subtracts minimum and scales to maximum. Per-pattern (no baseline) scales to maximum only. Global uses the same scale across all patterns.

Peak emphasis: a pre-normalisation power transform. At p=1 (default) this is a no-op; higher values boost peaks relative to noise.

Noise floor: normalised values at or below the threshold (0–5%) become zero before interpolation, removing background noise streaks without affecting genuine peaks.

Pattern markers: tick Pattern markers (right edge) to draw a tick at each pattern's exact Y position on the right edge of the plot.

Gridlines: off by default. When enabled, dashed lines are drawn at every tick position.

The stacked plot

The stacked plot shows each diffractogram as an intensity-vs-2θ line, offset vertically into bands. A floating tooltip follows the mouse cursor showing the current 2θ angle — visible regardless of scroll position.

Order: patterns appear bottom to top in file-table order (index 0 at the bottom, last index at the top), matching the intensity map in sequence mode. Tick Reverse order to flip. Drag rows by the grip handle (⠿) on the Files tab to reorder freely.

Per-pattern normalisation: each diffractogram is independently scaled to fill its band.

Colour: all-black by default. Untick All black to apply a colour ramp (Viridis, Plasma, Inferno, Cool, Warm, Rainbow, or Custom per-pattern).

Legends: drawn directly on the canvas and draggable within each band. The Snap legends selector aligns all legends by left edge, centre, or right edge. Right-clicking the canvas gives Copy image / Save image as… with legends included.

Output size and reproducibility

By default both plots scale to fill the browser width. For consistent figures, tick Lock plot size and enter explicit pixel dimensions. Save the settings JSON once the layout is right — dimensions are restored on every future session.

File-naming and Y values

The variable value is extracted from the last numeric segment of the filename, e.g. sample_150.xy gives 150. XRDML files extract the value from embedded metadata. Always check and correct auto-extracted values. If filenames contain no numbers the Y value is left blank; the stacked plot works normally but the intensity map (stimulus mode) requires Y values to be entered manually.

Save and load settings

The Save settings… and Load settings… buttons on the Files tab preserve all control choices for both plots in a JSON file. Note: settings only — pattern data is not included (use Export series for that).

Tips

  • Both plots auto-update on any settings change after a short delay.
  • The floating tooltip shows 2θ (and stimulus value on the intensity map) at the cursor position regardless of scroll — useful for tall stacked plots or large intensity maps.
  • For cooling/heating/cooling series: load files, drag into the correct sequence order, set Y-axis mode to By sequence order, then export to CSV so you never have to rearrange again.
  • Two ways to export plots: Copy to clipboard (PNG at full canvas resolution) or right-click → Copy image / Save image as….
  • Keep axis/box weight modest (1.5–2 px) for screen viewing; increase to 3–4 px for publication exports.
