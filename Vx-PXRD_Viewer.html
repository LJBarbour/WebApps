About Vx-PXRD Viewer

This app visualises a series of powder X-ray diffractograms collected under a variable condition — temperature, pressure, time, relative humidity, or any other parameter — by combining them into a single figure. It also handles series where the patterns are simply different phases or materials rather than a parametric scan.

Two complementary views are provided: a greyscale (or coloured) intensity map and a more conventional stacked line plot. The same data underlies both views; switch between them with the tabs above.

Workflow

  • On the Files tab, drop your data files or a .zip archive of them. The app will try to extract the variable value from each filename automatically.
  • Check the auto-detected values in the file table and edit any that are missing or wrong. Each row also has a Legend label field for the stacked plot — the Y-value plus unit is used as the default.
  • Reorder rows using the up/down arrows in the Order column, or click Auto-sort to restore the canonical order. Use the ✕ button to remove individual files.
  • Switch to Intensity Map or Stacked Plots, adjust the settings on the right, and the plot updates automatically as you change controls.

The intensity map

The intensity map is a 2D image of the entire dataset. The horizontal axis is 2θ, the vertical axis is the variable condition, and the brightness of each pixel encodes the peak intensity at that (2θ, condition) coordinate.

How it is built: each diffractogram is resampled onto a uniform 2θ grid and normalised (by default with a per-pattern baseline subtraction). For every row of pixels in the output image, the app finds the two patterns that bracket the row's condition value, and linearly interpolates the normalised intensities between them. The result is a smoothly shaded map where peaks appear as continuous bands and any shift, broadening, or appearance of new reflections with changing condition is immediately visible.

Reading the map: a vertical streak means a peak that holds its position over the range of conditions. A diagonal streak indicates a peak that shifts with the condition (typical of thermal expansion, lattice swelling, or pressure-induced compression). A streak that fades and another that appears nearby usually indicates a phase transition. Discrete jumps suggest abrupt structural changes.

Contrast and colour: the gamma slider stretches or compresses the intensity scale — values below 1 boost weak features (recommended for highlighting minor peaks), values above 1 emphasise only the strongest peaks. The peak and background colours can be set independently, so the conventional black-on-white can be flipped to white-on-black, or replaced with any duotone scheme.

Normalisation: Per-pattern & baseline subtracts each pattern's minimum (its baseline) and scales to the maximum — best when patterns have varying backgrounds. Per-pattern (no baseline) scales to the maximum only, preserving relative background levels. Global uses the same scale across all patterns, which preserves absolute intensity changes but can wash out weaker patterns.

Peak emphasis: a pre-normalisation power transform applied to each pattern individually. The pattern's baseline is subtracted (so noise is centred near zero), then the result is raised to the power p. At p=1 (default) this is a no-op. At p=2 the intensities are squared, which improves signal-to-noise ratio because peaks of amplitude A grow to A² while noise of amplitude N shrinks relatively to N²/A² — a quadratic gain in contrast. Higher powers (3–4) further suppress noise but make the brightest peaks dominate the visual scale. Especially helpful when some patterns are much noisier than others (e.g. high-temperature data) and per-pattern normalisation would otherwise bring their noise up to the same brightness as real peaks in cleaner patterns.

Noise floor: a percentage of the maximum peak height (0–5%). Applied to each pattern's normalised intensity array before the map is built — any value at or below the threshold becomes a hard zero, and remaining values are linearly rescaled so peak contrast is preserved. The interpolation between patterns then operates on clean data rather than on noise, so faint streaks vanish completely rather than just being dimmed. Set to 0% by default; 1–2% is usually enough to clear background noise from typical PXRD data. Higher values will start to erase weak but genuine peaks.

Pattern markers: the intensity map's Y axis is continuous, so the actual measurement positions can be hidden between interpolated rows. Tick the Pattern markers (right edge) option in the Data & scale group to draw a small tick on the right side of the plot at each pattern's exact Y value — useful when you want to be transparent about where the data was actually measured versus where it was interpolated.

Gridlines: off by default. When enabled, dashed lines are drawn at every tick position in the chosen colour and weight.

The stacked plot

The stacked plot shows each diffractogram as a conventional intensity-vs-2θ line, with the patterns offset vertically into bands so they don't overlap. The Y axis has no ticks (the absolute intensity is not generally meaningful between patterns) but is labelled "Intensity" by convention.

Order: the patterns appear from bottom to top in the file order shown on the Files tab. With Y-sorted data this means the lowest-condition pattern is at the bottom, matching the intensity map's orientation. Tick Reverse order to flip this. Manual reordering on the Files tab is respected directly.

Per-pattern normalisation: each diffractogram is independently scaled to fill its band, so subtle peaks in low-intensity patterns are visible alongside strong peaks in high-intensity patterns.

Colour: the default is all-black diffractograms. Untick All black to use one of six colour ramps (Viridis, Plasma, Inferno, Cool, Warm, Rainbow); the ramp is applied from the first to the last pattern in the file order.

Plot box: by default only the bottom (X) axis is drawn. Tick Show plot box for a full rectangle. The axis/box weight is independent of the diffractogram line weight.

Legends: each pattern's legend label is drawn directly on the plot and can be repositioned with the mouse. Hover over a legend to see the cursor become a grab handle, then drag it anywhere within its band. The Snap legends selector controls horizontal alignment across all legends: Left edge (the default — every legend's left edge sits on the same vertical line), Center (all legend midpoints aligned), Right edge (all right edges aligned, useful when label widths vary a lot), or Off (each legend positioned independently). Dragging any one legend horizontally moves the entire stack when snapping is on; switching modes keeps the widest legend visually anchored and rearranges the others around it. The Reset button clears all positions and returns to defaults. Because legends are drawn on the canvas itself (not as a separate overlay), right-clicking the plot and choosing Copy image or Save image as… in the browser produces a complete figure with the legends in place.

Output size and reproducibility

By default both plots scale horizontally to fill the available browser width, which is convenient for exploration but means the same data can produce figures of different absolute dimensions on different days. For consistent figure preparation, tick Lock plot size (in the Output size group on each settings panel) and enter explicit pixel dimensions. The intensity map locks both width and height; the stacked plot locks the width — its height naturally follows from the number of patterns multiplied by the band height. Save the settings file once the layout is right, and the same dimensions are restored on every future session.

File-naming and order

Input files are plain text with two or more whitespace- or comma-separated columns. The first column is 2θ in degrees; the second is intensity. Any additional columns (e.g. the estimated standard deviation in .xye files exported by CSD Mercury) are silently ignored. Single-value header lines such as the wavelength line in .xye files are also skipped automatically. Lines starting with #, !, or ; are treated as comments and skipped. Extensions .xy, .xye, .dat, and .txt are all accepted.

The variable value is extracted from the last numeric segment of the filename, preceded by an underscore or hyphen. For example, sample_KD66_150.xy gives 150. The legend label is auto-built from the value plus any unit detected in the Y-axis label string (e.g. 150 °C). Always check the auto-extracted values and override any that are wrong.

Non-numeric series: if your filenames don't contain numbers (e.g. α-phase.xy, β-phase.xy, sample_A.xy), the Y value is left blank and the legend defaults to the filename stem. Patterns are sorted in natural alphabetical order. The stacked plot works normally; the intensity map cannot be drawn without Y values (it would be physically meaningless) but is simply not used in this workflow.

Save and load settings

The Save settings… and Load settings… buttons on the Files tab let you preserve your control choices for both plots in a small JSON file. This is useful when you want consistent appearance across figures prepared over several sessions, or when sharing a publication style with a colleague. Save creates a file you can place anywhere on your computer; Load reads it back and applies every setting (settings only — the file table and any pattern data are unaffected).

Tips

  • Both plots auto-update on any settings change after a short delay. Use the Render now button only if you want an immediate refresh.
  • The Y-axis label on the intensity map and the legend label on each pattern are independent: the former describes the variable being plotted, the latter is just the per-pattern annotation.
  • For variable-temperature data, a typical legend label might be "30 °C" or "150 °C"; for variable-pressure, "5 bar"; for time-resolved, "10 min", etc.
  • Two ways to export the plots: the Copy to clipboard button places a PNG at full canvas resolution; right-clicking the plot offers the browser's standard Copy image and Save image as… options, which save the same content directly to file or clipboard. Both methods include the legends on the stacked plot.
  • The plot box and X axis on the stacked plot share the same "Axis/box weight" — keep it modest (1.5–2 px) for screen viewing, increase to 3–4 px for high-resolution publication exports.
