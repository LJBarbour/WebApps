Isotherm Fitter

User Guide

This app fits sorption isotherm data to any of 26 standard isotherm models using nonlinear least-squares (Levenberg–Marquardt). Load a two-column CSV (pressure, uptake), select a model, optionally adjust initial guesses, and click Fit Isotherm. Use Auto-Select Best Model to rank all models by AICc.

Loading data

Click the drop zone or drag and drop a CSV file. Column 1 must be pressure, column 2 uptake. Delimiters: comma, tab, or semicolon. Lines that cannot be parsed as two numbers are treated as metadata or headers and skipped for fitting (but retained for export).

Fitting

Select a model from the left panel. The equation is shown graphically below the selector. Initial guesses are pre-filled with sensible defaults but can be adjusted. Click Fit Isotherm to run the optimisation. Fitted parameters, standard errors, R² and SSR appear in the Summary tab. The fit is drawn over the data in the Plot tab.

Auto-Select Best Model fits all 26 models and ranks them by AICc (Akaike Information Criterion, corrected). Lower AICc is better; a difference <2 is statistically indistinguishable. Click any row in the results table to select that model.

Exporting results

Click Export Results CSV to save the fitted parameters, goodness-of-fit statistics, fitted vs. raw data, and correlation matrix. All metadata from the input file (and any entered in the Summary panel) are written to the header, so the file is ready for use with the IAST and Sorption Enthalpy Calculators.

Shared metadata vocabulary

This app is part of a suite of sorption tools for (1) unit conversion, (2) isotherm fitting, (3) IAST calculations, and (4) sorption enthalpy calculations. Metadata keywords are passed through from the input file to the output CSV, ensuring data continuity through the pipeline.
