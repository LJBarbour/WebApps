Isotherm Plotter — Guide

How this app reads your files and builds the figure
Purpose

This app has one job: load several sorption isotherm CSV files and draw them together as a single publication-ready figure. It does not fit equations or convert units itself — use Isotherm_Fit to fit a model, and Sorption_Unit_Converter to put raw data into consistent units, then drop the resulting files in here.

Loading files

Drag and drop one or more CSV files anywhere on the window. Each file becomes one entry in the Datasets list on the left. There is no file-picker button — drop is the only way in.

Accepted file formats
SourceWhat the app reads
Isotherm_Fit outputMetadata header, the Model/Parameter,Value,Std Error block, and the Pressure,Uptake,Fitted,Residual table. Uptake becomes the data points.
Sorption_Unit_Converter outputMetadata header and a Pressure (unit),Uptake (unit) table. If the file has two blocks of data separated by a blank line, the first block is treated as sorption and the second as desorption.
Fitted lines are recomputed, not just connected

When a file carries a recognised Model name and its fitted parameters, the fitted-line overlay is recomputed directly from that equation — the same 26 isotherm models used in Isotherm_Fit, IAST_Calculator and Sorption_Enthalpy — sampled at 400 points across the dataset's pressure range. This gives a properly smooth curve rather than straight segments between the (often sparse or unevenly spaced) fitted values already sitting in the file. A card's Fitted line toggle shows ✓ smooth curve when this succeeds. If the model name isn't recognised, or a parameter needed to evaluate it is missing, the toggle instead shows ⚠ straight segments and falls back to connecting the file's own Fitted column values.

Sorption / desorption legs

A dataset with two blocks of data gets independent Sorption and Desorption toggles in its card. Sorption points are always drawn filled; desorption points are drawn open, in the same colour and shape. A dataset with only one block gets a single Data points toggle instead.

Marker shapes

Each dataset gets its own marker shape as well as its own colour, chosen from the Marker shape dropdown in its card and cycled automatically as datasets are loaded. Only shapes with both a filled and an open form are offered — circle, square, triangle, diamond, inverted triangle — so datasets stay distinguishable by shape and the sorption/desorption fill convention even in a figure printed in black only.

Pressure units

Each dataset's pressure unit is read from its metadata (or guessed from the column header, or assumed to be bar as a last resort — flagged in the card if so). All datasets are then converted automatically to the single Pressure display unit chosen at the top of the left sidebar, so mixed-unit files can still share one x-axis.

Uptake units

The Required uptake unit control at the top of the sidebar is set automatically from the first dataset you load, and every other dataset is converted to it — using the same conversion engine as Sorption_Unit_Converter. If a dataset's own uptake unit is missing, select it in the card. If it differs from the required unit, the card shows a Convert to required uptake unit box asking only for whatever that specific conversion actually needs (never all of it): sorptive molecular weight for a mass⇄moles conversion, host mass for a per-gram⇄absolute conversion, host formula or molecular weight for mol/mol. Sorptive identity and molecular weight are detected automatically where possible (from the file's own metadata, or looked up by gas name); a host formula is parsed into a molecular weight automatically too. Any value still missing shows pink, and the card states plainly what conversion is being applied — or what it's still waiting on, with that dataset left out of the plot until then.

Publication output

The right-hand panel controls axis ranges, fonts, tick styling, gridlines, point/line size, and the legend — the same controls used across the other apps in this set. Save Plot Image and Copy Plot to Clipboard render the figure at the chosen output size.
