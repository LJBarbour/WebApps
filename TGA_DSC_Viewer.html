TGA / DSC Viewer

User Guide

Overview

This app displays TGA (thermogravimetric analysis) and DSC (differential scanning calorimetry) data on a shared temperature axis. TGA has its own y-axis on the left; DSC on the right. Either or both files can be loaded independently. The first derivative of TGA (DTG) can be overlaid on the same plot.

File Format

The app accepts plain-text files in any common delimiter format (CSV, TXT, DAT). Files may use ASCII or UTF-16 encoding — TA Instruments files are handled automatically.

  • All header lines are ignored until the keyword StartOfData is found.
  • From the line after StartOfData, column 2 is read as temperature (°C) and column 3 as the signal. Column 1 (typically time) is ignored.
  • Columns may be separated by commas, semicolons, tabs, or whitespace.
  • A Size field in the TGA header (e.g. Size 12.34 mg) is read automatically and used to express TGA weight as % of initial mass.
Loading and Clearing Data

Click or drag a file onto the TGA or DSC drop zone. The file name, point count, temperature range, and sample size (if present) are shown in the File Info panel. Click ✕ Clear next to either channel header to remove that dataset without restarting the app.

Heating and Cooling Legs

For DSC files that contain multiple temperature ramps (e.g. a heat–cool cycle), the app automatically detects each leg using a sliding-window direction algorithm that is robust to noisy temperature data and spurious points. Each leg is labelled Heating or Cooling and given a distinct colour. Individual legs can be shown or hidden using the checkboxes that appear below the DSC drop zone. The Color by leg option in the right panel switches between per-leg colours and a single colour for all legs.

DTG — First Derivative

Check Show DTG below the TGA drop zone to overlay the first derivative of the TGA signal. The derivative is computed by central differences and smoothed with a boxcar window whose width is set by the Smoothing window slider. The DTG curve shares the temperature axis but has no y-axis scale — it is displayed for qualitative shape reference only.

Axis Ranges

The Temperature Range fields in the left sidebar set the x-axis limits exactly. The Axis Ranges panel on the right sets the y-axis limits for TGA and DSC independently. All four limits are applied as hard boundaries — the axis starts and ends at exactly the value you enter, with ticks computed within those limits. Leave a field blank to revert to automatic scaling.

Zooming and Panning

Left-drag on the chart to draw a zoom rectangle (x-axis only; y-axis auto-scales to the zoomed range). Right-drag to pan. The Temperature Range fields update to show the current zoom. Click ⟲ Reset or clear the Temperature Range fields to restore the full range.

Tooltip

Hover over the chart to see the temperature and the nearest TGA, DTG, and DSC values at the cursor position.

Export

Export Combined CSV saves temperature, TGA, and DSC in three columns. If both datasets are loaded, the DSC signal is interpolated onto the TGA temperature grid. The DTG column is included when active.

Save Plot Image renders the chart at the resolution set in the Width/Height fields and saves as PNG or JPEG.

Save Settings JSON saves all current control values (colours, line widths, axis ranges, font, grid style, etc.) to a JSON file. Load Settings JSON restores a previously saved set of settings instantly.
